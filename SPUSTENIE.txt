KVANTOVÁ RULETA PRO V2
======================

JEDINÝ ZDROJ: index-NOVY-V2.html
RUNTIME:      index.html (generovaný cez npm run sync-v2)

────────────────────────────────────────────────────────────
REŽIM DEV (vývoj, testy)
────────────────────────────────────────────────────────────
Spustenie:
   npm run dev
   alebo  npm start   (= sync-v2 + electron .)

Povinné súbory / zložky:
   index-NOVY-V2.html, index.html, main.js, package.json
   scripts/, styles/, node_modules/

Nepovinné:
   app/  (iba ak testuješ packaged build)

Kontrola stavu:
   npm run check:workspace

────────────────────────────────────────────────────────────
REŽIM PLAYER (hra)
────────────────────────────────────────────────────────────
Spustenie:
   app\RULETA.exe
   alebo  npm run play
   alebo  RULETA.lnk v koreni
   alebo  SPUSTIT-RULETA.bat

Povinné:
   app/  (celý priečinok — RULETA.exe + runtime)
   index.html, styles/, scripts/  (živý UI — main.js načíta externý index)

Nepovinné:
   node_modules/  (na hráčskom PC netreba)

────────────────────────────────────────────────────────────
BUILD A HYGIENE (Balík 7C)
────────────────────────────────────────────────────────────
Po úprave kódu:
   1. Zatvor hru (RULETA v Správcovi úloh)
   2. npm run sync-v2
   3. npm run test:v2:master   (alebo test:v2:ci)
   4. npm run dist             (postdist spustí clean:build)
   5. app\RULETA.exe

Čistenie build artefaktov:
   npm run upratat
   npm run clean:build   (upratat + kontrola .build-* / win-unpacked)

Jediný produkčný build:  app\
Zakázané v koreni: .build-*, win-unpacked, dist-*, portable RULETA.exe

────────────────────────────────────────────────────────────
AUDIT DISKU (Balík 7E)
────────────────────────────────────────────────────────────
   npm run audit:disk

────────────────────────────────────────────────────────────
ODKAZ NA PLOCHE
────────────────────────────────────────────────────────────
   Nainstaluj-na-plochu.bat   alebo   npm run desktop

AVAST (jednorazovo):
   npm run avast
   Výnimka na celý priečinok QuantumApp (vrátane app\)

PREČO NIE JE RULETA.exe V KORENI?
Starý portable rozbali exe do Temp. Teraz normálny Electron v app\.

Git: len jeden workspace v tomto priečinku — žiadne _gh_push / _gh_clone.
